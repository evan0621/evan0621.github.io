打殭屍遊戲機

打殭屍遊戲機

作品簡介

這款打殭屍遊戲機是一個基於 Arduino 的迷你遊戲裝置，設計靈感源自小時候經典的手機遊戲。這個裝置使用了 8x8 LED 點矩陣顯示器、雙位七段顯示器以及三顆按鈕，模擬了打擊殭屍的場景。殭屍會以紅色方塊的形式出現在屏幕上方，玩家需挑戰在30秒內獲得最高分數，這個過程不僅考驗玩家的反應力，還增添了懷舊的遊戲樂趣。

展示影片

元件與結構

  • 8x8 LED 點矩陣顯示器：作為主要的遊戲顯示區域，利用紅色 LED 點顯示殭屍的位置。
  • 雙位七段顯示器：顯示玩家的當前分數，隨著擊中殭屍次數累加。
  • 三顆按鈕：每個按鈕分別對應點矩陣顯示器的不同區域，玩家需根據殭屍的出現位置按下相應按鈕。
  • Arduino 主控板：核心控制模組，負責處理按鈕輸入、計算分數以及更新 LED 顯示。

電路連接說明

在電路設計中，8x8 點矩陣、按鈕和七段顯示器通過連接 Arduino 主板完成控制。七段顯示器需要解碼 IC 的協助，以便 Arduino 顯示數字分數。每個按鈕的輸入信號通過對應的數位接口傳送到 Arduino，用於判斷玩家的反應時間及對應擊打是否成功。

Whack-a-Zombie Arcade Game

Overview

This whack-a-zombie game console is an Arduino-based mini gaming device, inspired by a classic mobile game from childhood. It uses an 8x8 LED matrix display, a two-digit seven-segment display, and three buttons to simulate a zombie-whacking scene. Zombies appear as red blocks at the top of the screen, and the player races to score as many points as possible within 30 seconds — a test of reflexes with a dose of nostalgic fun.

Demo Video

Components & Structure

  • 8x8 LED matrix display: The main game display area; red LED dots show the zombies' positions.
  • Two-digit seven-segment display: Shows the player's current score, accumulating with each zombie hit.
  • Three buttons: Each button corresponds to a different region of the matrix; the player presses the matching button based on where a zombie appears.
  • Arduino board: The core control module — handles button input, score counting, and LED display updates.

Circuit Notes

In the circuit design, the 8x8 matrix, buttons, and seven-segment display are all wired to the Arduino board. The seven-segment display requires a decoder IC so the Arduino can display the numeric score. Each button's input signal goes to a corresponding digital pin, used to judge the player's reaction time and whether a hit was successful.
