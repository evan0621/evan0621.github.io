醫療內視鏡辨識APP

醫療內視鏡辨識APP

作品簡介

醫療內視鏡的型號與尺寸繁多，因此，醫護人員在日常工作中，經常需要花費大量時間來查找和對應不同型號的內視鏡，然而，手動辨識過程耗時且容易出現錯誤，因此開發一個自動辨識APP成為了這個專案的目標。

展示影片

技術實現

  • 模型訓練：我們採用了YOLO進行辨識，該模型經過大量圖片的訓練後，能夠自動識別出內視鏡的形狀特徵並匹配相應型號。

  • 部署製手機端：考慮到醫護人員的使用便利性，採用手機APP簡單易懂的操作介面，用戶只需開啟相機對準內視鏡，即可在螢幕上看到即時辨識結果，無需額外的操作步驟。

結論

本專案開發的內視鏡辨識APP，成功解決了醫護人員在辨識型號時的困擾，提升了效率並降低錯誤風險。透過YOLO模型的準確辨識，搭配手機端的即時顯示，使用者可快速獲取內視鏡型號，簡化操作流程。此APP未來將成為醫療工作中高效且可靠的輔助工具。

Medical Endoscope Recognition App

Overview

Medical endoscopes come in a wide variety of models and sizes, so in their daily work medical staff often spend a great deal of time looking up and matching different endoscope models. Manual identification is time-consuming and error-prone, so the goal of this project was to develop an automatic recognition app.

Demo Video

Technical Implementation

  • Model training: We used YOLO for recognition. After training on a large set of images, the model automatically identifies the shape features of an endoscope and matches the corresponding model number.

  • Mobile deployment: For the convenience of medical staff, the app uses a simple, intuitive interface — the user just opens the camera and points it at an endoscope to see real-time recognition results on screen, with no extra steps required.

Conclusion

The endoscope recognition app developed in this project successfully solves the difficulty medical staff face when identifying endoscope models, improving efficiency and reducing the risk of errors. With accurate YOLO-based recognition and real-time display on a phone, users can quickly obtain the endoscope model number with a simplified workflow. This app is set to become an efficient and reliable assistant in medical work.
